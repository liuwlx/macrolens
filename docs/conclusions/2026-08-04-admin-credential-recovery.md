# MacroLens 管理员凭据恢复结论报告

- 任务：`ML-20260804-003`
- 范围：现有唯一启用管理员的受控凭据恢复、会话撤销、真实认证验证与审计确认
- 管理员账号：`admin@macrolens.example.com`
- 结论：恢复完成，认证与退出验证通过，旧会话已撤销，服务持续就绪；本报告不包含任何凭据、数据库秘密或认证派生值。

## 1. 问题与场景

本次场景是管理员无法继续使用既有登录凭据，需要在不新建重复管理员、不泄露数据库或认证秘密、不保留旧登录会话的前提下恢复访问。该操作涉及最高权限账号，错误选择用户、把敏感值写入命令历史/日志/审计、只改密码却不撤销旧会话，都会形成严重安全风险。

恢复对象必须先通过数据库事实唯一确定。只存在一个启用状态的管理员，其邮箱为 `admin@macrolens.example.com`；没有通过猜测、固定默认账号或模糊匹配选择目标。恢复期间没有查询、输出或记录原有密码派生值，也没有把临时凭据写入仓库、报告、提交信息或审计详情。

## 2. 分析过程

首先把验收拆成五个独立条件：目标身份唯一、凭据更新成功、旧会话全部失效、真实 HTTP 认证闭环成功、审计记录完整且不含敏感材料。仅看到数据库行更新或登录成功都不足以单独证明恢复安全。

身份确认以“启用状态 + 管理员角色”为条件查询，并要求结果唯一；最终目标邮箱与预期账号一致。临时密码由系统随机生成，只在恢复操作的受控内存路径中使用，不读取旧值。更新凭据后，同一恢复流程撤销该用户已有 refresh 会话，避免旧浏览器或泄露会话继续有效。

随后使用真实 HTTP 登录路径验证响应状态为 200，并校验返回身份的邮箱与目标账号完全一致；再调用真实退出路径，响应状态为 204。退出后数据库复核该用户活动会话数为 0。审计表中存在 `credential_reset` 事件，但事件内容只描述恢复动作和目标身份，不包含密码、认证派生值或其他秘密。最后确认服务 ready 端点保持 200，证明恢复操作没有破坏正在运行的 API。

## 3. 解决流程

1. 读取工程、安全和组织约束，确认秘密不得进入仓库、日志或报告，认证恢复必须可审计。
2. 在真实数据库中按启用状态和管理员角色定位账号，要求结果唯一，并确认邮箱为 `admin@macrolens.example.com`。
3. 不读取旧密码派生值；生成随机临时密码并更新目标管理员凭据。
4. 撤销该管理员的全部旧 refresh 会话，使既有登录状态立即失效。
5. 检查审计流水已写入 `credential_reset`，并确认审计内容没有敏感认证材料。
6. 通过真实 HTTP 登录接口验证 200 和邮箱匹配。
7. 通过真实 HTTP 退出接口验证 204；随后确认活动会话数为 0。
8. 再次检查服务 ready 端点为 200，确认恢复操作未影响服务可用性。
9. 仅新增并提交本七节结论报告；不修改应用代码、运行配置或现有服务进程。

## 5. 值得沉淀的经验与模式

1. 管理员恢复必须先证明目标唯一；“看起来像管理员”的邮箱或首条查询结果都不能作为授权依据。
2. 恢复流程不需要读取旧密码派生值。只应生成新随机凭据、执行单向更新并验证新认证路径。
3. 密码重置与会话撤销必须视为一个安全动作。只更新密码会留下旧 refresh 会话继续访问的窗口。
4. 数据库更新成功不等于用户可以登录；必须通过真实 HTTP 登录、身份匹配和退出完成端到端验收。
5. 退出成功也不等于服务端状态干净；还需确认活动会话计数归零。
6. 审计记录应证明“谁对哪个账号执行了什么动作”，但绝不能保存凭据、认证派生值或可重放材料。
7. 高权限恢复后要检查服务健康，避免把一次数据修复误当成无运行影响的操作。
8. 临时凭据必须通过独立受控渠道交付，并要求管理员尽快更换；结论报告和 Git 永远不承担秘密传递职责。

## 6. 更好的初始提示词

## 7. 一次解决的更优方案提示词

长期更优方案是不直接分发可长期使用的临时密码，而是提供正式的 break-glass 管理员恢复命令：要求双人审批或一次性授权，唯一定位启用管理员，生成短时一次性恢复凭证，强制首次登录立即设置新密码，并在同一事务中撤销全部旧会话。命令只输出恢复凭证的受控交付引用，不输出秘密本身；审计记录请求人、审批人、目标账号、原因、时间和结果，并对敏感字段做结构化禁止。

> 请为 MacroLens 实现一个可审计的 break-glass 管理员恢复流程：CLI 只能在显式恢复模式和双人审批引用存在时运行；目标必须是唯一启用管理员；生成短时、单次使用的恢复凭证，首次使用后强制设置新密码；凭据更新、旧会话撤销和恢复凭证失效必须原子完成。任何输出、日志、异常和审计结构都禁止包含密码、数据库秘密或认证派生值。提供 0/1/多管理员、过期/重复使用、并发恢复、旧会话拒绝、登录/退出、审计脱敏和服务健康测试，并把秘密交付委托给专用 secret manager，而不是终端或 Git。
